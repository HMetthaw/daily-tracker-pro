# Product Decisions

## 2026-05-18 - PWA First, Native Later

Decision: use the PWA as a feedback/demo channel while keeping the Expo native app for the later App Store path.

Reason: Apple Developer Program cost can wait, while the PWA lets people try the workflow now.

## 2026-05-18 - Recap Uses Elapsed Days Only

Decision: weekly recap evaluates only days that have happened. On Sunday, it evaluates the previous completed week.

Reason: future days should not count as failed days.

## 2026-05-18 - Projects Use Date Ranges

Decision: projects have start and end dates, but planning is still done as concrete steps on calendar days.

Reason: real projects cross month boundaries, but simple day-based planning is easier than a full project management system.

## 2026-05-18 - Paid Features Later

Decision: keep basic tracking free in the early product and explore paid professional project features later.

Reason: retention and workflow value should be validated before adding payments.
