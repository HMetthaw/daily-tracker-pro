# App Store Plan

## Current Status

- PWA demo is live through GitHub Pages.
- Expo React Native app exists for future native work.
- App is not yet ready for App Store submission.

## Apple Requirements To Plan Around

- Apple Developer Program membership is required for App Store distribution and costs 99 USD per membership year according to Apple Developer support.
- TestFlight is useful for beta testing, but production launch still needs App Review.
- Paid digital features should use Apple's In-App Purchase system and follow App Review Guidelines.
- If revenue qualifies, App Store Small Business Program may reduce Apple's commission. Confirm eligibility before launch.

Sources:

- Apple Developer membership: https://developer.apple.com/support/compare-memberships/
- App Review Guidelines: https://developer.apple.com/app-store/review/guidelines/
- App Store Small Business Program: https://developer.apple.com/app-store/small-business-program/

## Pre-TestFlight Checklist

- Replace placeholder icon with production icon.
- Verify app name and bundle identifier.
- Decide privacy policy URL and support URL.
- Add export/backup story or clearly state local-only storage.
- Test local notifications on real iPhone.
- Test Czech and English UI.
- Test offline behavior.
- Confirm no broken or placeholder paid screens are present.

## First App Store Version

Recommended launch scope:

- Today checklist.
- Recurring tasks.
- Future one-time tasks.
- Week view with day quick-add.
- Project planning with date ranges.
- Weekly recap with chart.
- Dark mode.
- Czech and English.
- Local notifications.

Avoid in v1:

- Accounts.
- Payments.
- Cloud sync.
- Team sharing.
- Complex project dependencies.

## Paid Features Later

When paid features are added, prepare:

- Clear paywall copy.
- Restore purchases.
- App Store subscription or non-consumable product setup.
- App Review test account/instructions if needed.
- Graceful behavior when purchases are unavailable.
