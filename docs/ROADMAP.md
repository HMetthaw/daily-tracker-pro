# Roadmap

## Phase 0 - PWA Feedback Demo

Goal: validate whether people understand the workflow and would use it repeatedly.

- Keep GitHub Pages PWA live for quick sharing.
- Polish Czech copy and mobile layout.
- Fix recap, calendar, and task creation issues from real feedback.
- Add lightweight data export/import so early users do not lose their setup.
- Collect 5-10 user conversations before committing to paid features.

## Phase 1 - Native iPhone MVP

Goal: make the app reliable enough for daily use without a computer.

- Move current PWA behavior into the Expo/native app.
- Use local notifications for task reminders and weekly recap.
- Improve local persistence and backup.
- Prepare TestFlight distribution.
- Create App Store assets: icon, screenshots, privacy copy, support URL.

## Phase 2 - App Store Launch

Goal: release a simple, credible public v1.

- Enroll in Apple Developer Program.
- Build and submit through TestFlight first.
- Resolve App Review issues before public launch.
- Launch with free core functionality: recurring tasks, one-time tasks, projects, weekly recap, dark mode, Czech/English.
- Track qualitative feedback manually before adding analytics.

## Phase 3 - Paid Features

Goal: monetize professional value without hurting the basic tracker.

Candidate paid features:

- Unlimited active projects.
- Project templates for construction workflows.
- PDF/CSV project export.
- Advanced project recap and monthly reports.
- Cross-device sync and backup.
- Shared project read-only links.
- Reminder presets and notification packs.

Recommended first paid experiment:

- A one-time "Pro" unlock or simple monthly subscription focused on project templates + export.

Avoid early:

- Locking daily recurring tasks behind a paywall.
- Building complex team collaboration before solo users prove the workflow.
- Adding Gantt dependencies before the simple project calendar is validated.

## Phase 4 - Professional Workflow Expansion

Goal: make the app useful for small crews and recurring construction jobs.

- Project templates by job type.
- Checklist libraries.
- Before/after photo attachments.
- Material delivery reminders.
- Client/address metadata.
- Archive completed projects.
- Search across projects.
